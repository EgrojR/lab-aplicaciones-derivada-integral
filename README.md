# Laboratorio · Aplicaciones de la derivada y de la integral

Explorador interactivo para **Cálculo de una variable** (UIS, 2026-2): razones de cambio relacionadas, problemas de optimización, áreas entre curvas y sólidos de revolución (discos, arandelas y cascarones cilíndricos).

- Publicado en GitHub Pages: https://egrojr.github.io/lab-aplicaciones-derivada-integral/
- Ejercicios tomados de la *Miscelánea de aplicaciones de la derivada* (números D-n: cap. 1, ej. 1–55; cap. 4, ej. 191–250) y de la *Miscelánea de aplicaciones de la integral* (números I-n: áreas 1–74, discos y arandelas 123–191, cascarones 192–250).
- Cada ejercicio trae un **itinerario** de puntos de control conceptuales; al completarlo el laboratorio entrega un código que se pide en el cuestionario de Moodle («Examen final»).
- Parámetros de URL: `?e=rc18` abre un ejercicio (ids: `rc…`, `opt…`, `area…`, `sol…`); `&tab=itinerario|planteamiento|teoria`; `&embed=1` modo compacto para Moodle; `?m=rc|opt|area|sol` abre un módulo.
- Un solo archivo (`index.html`); usa KaTeX desde CDN. La matemática de todos los ejercicios fue verificada con sympy (ver `verifica.py` en la carpeta de trabajo del docente).
